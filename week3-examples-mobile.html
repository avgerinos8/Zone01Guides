Προτεινόμενες Ασκήσεις & Παραδείγματα ανά Pattern (Week 3)

Αυτό το έγγραφο περιέχει 5 ολοκαίνουριες ιδέες πρακτικών προβλημάτων για το καθένα από τα 18 Patterns. Οι εκφωνήσεις είναι πλέον πιο αναλυτικές, δίνοντας ξεκάθαρο context για το τι πρέπει να πετύχει ο μαθητής. Κάτω από κάθε άσκηση υπάρχει ένα εννοιολογικό hint υλοποίησης.

1. The Accumulator (Result Variable)

  1. Υπολογισμός Παραγοντικού (Factorial): Γράψτε ένα πρόγραμμα που δέχεται έναν θετικό ακέραιο N και υπολογίζει το παραγοντικό του (N!). Για παράδειγμα, αν δοθεί το N=5, το αποτέλεσμα πρέπει να είναι 1 * 2 * 3 * 4 * 5 = 120. Χρησιμοποιήστε μια μεταβλητή για να χτίσετε το αποτέλεσμα.
    2. Hint: Αρχικοποιείς result = 1. Στο loop, πολλαπλασιάζεις το τρέχον result με το i (result *= i).
  2. Μήκος χωρίς την len(): Στη Go (αλλά και σε πολλές άλλες γλώσσες) υπάρχει η συνάρτηση len(). Γράψτε μια δική σας συνάρτηση που παίρνει ένα string, διατρέχει όλους τους χαρακτήρες του, και επιστρέφει πόσοι είναι συνολικά, προσομοιώνοντας τη συμπεριφορά της len().
    3. Hint: Αρχικοποιείς count = 0. Στο range loop (που απλά διατρέχει το string), κάνεις count++ αγνοώντας την τιμή του χαρακτήρα.
  3. CSV Builder: Σας δίνεται ένα array από User IDs (π.χ. [101, 102, 105]). Ο στόχος σας είναι να φτιάξετε ένα ενιαίο string όπου όλα τα IDs θα είναι ενωμένα με κόμμα, δηλαδή να επιστρέψετε "101,102,105".
    4. Hint: Αρχικοποιείς csv = "". Στο loop, προσθέτεις το ID και ένα κόμμα. Μετά το loop κόβεις το τελευταίο κόμμα (ή βάζεις το κόμμα μόνο αν δεν είσαι στο τελευταίο στοιχείο).
  4. Τελικό Υπόλοιπο Τράπεζας: Μια τράπεζα σας δίνει ένα array με τις ημερήσιες συναλλαγές ενός πελάτη. Οι θετικοί αριθμοί είναι καταθέσεις και οι αρνητικοί είναι αναλήψεις (π.χ. [100, -20, -10, 50]). Υπολογίστε ποιο θα είναι το τελικό υπόλοιπο του λογαριασμού αν ξεκινήσει από το μηδέν.
    5. Hint: Αρχικοποιείς balance = 0. Μέσα στο loop, απλά προσθέτεις την τρέχουσα συναλλαγή στο balance. Τα πρόσημα (+/-) αναλαμβάνουν τα υπόλοιπα.
  5. Αντιστροφή String (Reverse): Σας δίνεται η λέξη "hello". Σκοπός είναι να δημιουργήσετε μια νέα μεταβλητή που να περιέχει την ίδια λέξη αλλά γραμμένη ανάποδα ("olleh"), διαβάζοντας την αρχική λέξη κανονικά, γράμμα-γράμμα από την αρχή προς το τέλος.
    6. Hint: reversed = "". Μέσα στο loop: reversed = string(char) + reversed. Προσοχή, ο νέος χαρακτήρας πάει ΜΠΡΟΣΤΑ.

2. Min/Max Tracking

  1. Ο Κοντύτερος Δρομέας: Έχετε καταγράψει τους χρόνους 5 αθλητών στα 100 μέτρα, σε δευτερόλεπτα (π.χ. [10.5, 9.8, 11.2, 10.1]). Βρείτε ποιος ήταν ο καλύτερος χρόνος, δηλαδή ποιος αριθμός είναι ο μικρότερος στη λίστα.
    2. Hint: Αρχικοποιείς minTime = arr[0]. Αν το τρέχον time < minTime, το minTime παίρνει τη νέα τιμή.
  2. Το Πιο Ακριβό Καλάθι: Ένα 2D array (πίνακας) περιέχει τα καλάθια αγορών διαφόρων πελατών. Κάθε γραμμή είναι οι τιμές των προϊόντων που πήρε ένας πελάτης (π.χ. [ [5, 10], [20, 2], [50] ]). Βρείτε ποιο καλάθι έχει το μεγαλύτερο συνολικό κόστος.
    3. Hint: maxCart = 0. Εξωτερικό loop ανά καλάθι, εσωτερικό loop αθροίζει. Αν το sum > maxCart, ενημερώνεις το max.
  3. Η Μεγαλύτερη Πτώση Θερμοκρασίας: Σας δίνεται ένα array με τις θερμοκρασίες ενός μήνα. Βρείτε τη μέρα που καταγράφηκε η μεγαλύτερη *πτώση* ή *άνοδος* (διαφορά) σε σχέση με την ακριβώς προηγούμενη ημέρα. Θα χρειαστείτε την απόλυτη τιμή της διαφοράς.
    4. Hint: maxDrop = 0. Στο loop (από το index 1), υπολογίζεις τη διαφορά (abs(arr[i] - arr[i-1])). Αν > maxDrop, ανανεώνεις.
  4. Ο Πιο Κοντινός στο Μηδέν (Closest to Zero): Δίνεται ένα array με θετικούς και αρνητικούς αριθμούς. Βρείτε ποιος αριθμός βρίσκεται πιο κοντά στο μηδέν (π.χ. ανάμεσα στο 5 και το -2, το -2 είναι πιο κοντά). Σε περίπτωση ισοπαλίας, προτιμήστε τον θετικό.
    5. Hint: closest = arr[0]. Συγκρίνεις την απόλυτη τιμή (abs). Αν abs(num) < abs(closest), το closest = num.
  5. Καλύτερο Σκορ σε Video Game: Διαβάζετε ένα συνεχές (infinite) stream από σκορς παικτών. Το πρόγραμμα πρέπει να κρατάει το μεγαλύτερο σκορ όλων των εποχών (HighScore). Όποτε ένας νέος παίκτης ξεπερνάει αυτό το σκορ, να τυπώνεται στην οθόνη "New Record!".
    6. Hint: highScore = 0. Στο άπειρο/συνεχές loop, αν newScore > highScore, τύπωσε "Record!" και ανανέωσε τη μεταβλητή.

3. Boolean State Flag

  1. Αφαίρεση Πολλαπλών Κενών (Space Toggle): Έχετε ένα κείμενο που μπορεί να έχει πολλά συνεχόμενα κενά (π.χ. "Hello world"). Θέλετε να το τυπώσετε κρατώντας μόνο ένα κενό ανάμεσα στις λέξεις. Χρησιμοποιήστε έναν διακόπτη για να θυμάστε αν "μόλις τυπώσατε κενό".
    2. Hint: Αρχικά inSpace = false. Αν βρεις ' ' και το flag είναι false, τυπώνεις ' ' και το κάνεις true. Αν βρεις γράμμα, το κάνεις false.
  2. Εντοπισμός Μπλοκ HTML: Διαβάζετε έναν κώδικα HTML (π.χ.

    Hello

    ). Θέλετε να τυπώσετε ΜΟΝΟ το κείμενο που βρίσκεται έξω από τα tags, δηλαδή αγνοώντας ό,τι βρίσκεται ανάμεσα στα < και >. Ένας διακόπτης θα σας λέει πότε είστε μέσα σε tag.
    3. Hint: isText = true. Όταν διαβάζεις '<' γίνεται false. Όταν διαβάζεις '>' γίνεται true. Κάνεις accumulate μόνο όταν isText == true.
  3. Ταλάντωση (Zig-Zag): Θέλετε να ελέγξετε αν μια σειρά αριθμών κάνει "ζιγκ-ζαγκ", δηλαδή ο πρώτος είναι μικρότερος από τον δεύτερο, ο δεύτερος μεγαλύτερος από τον τρίτο, ο τρίτος μικρότερος κ.ο.κ. Ένας διακόπτης πρέπει να εναλλάσσεται σε κάθε βήμα.
    4. Hint: expectLarger = true. Ελέγχεις τη συνθήκη βάσει του flag. Στο τέλος της επανάληψης το κάνεις αντιστροφή: expectLarger = !expectLarger.
  4. Skip Block: Διαβάζετε ένα μεγάλο log αρχείο. Σας ενδιαφέρει να αποθηκεύσετε τα δεδομένα ΜΟΝΟ από τη στιγμή που θα συναντήσετε τη λέξη "START", μέχρι τη στιγμή που θα βρείτε τη λέξη "STOP". Τα υπόλοιπα πρέπει να αγνοηθούν.
    5. Hint: Με string ανίχνευση. record = false. Μόλις δεις τη λέξη εκκίνησης, αλλάζει η κατάσταση. Το print τρέχει μόνο αν record == true.
  5. Βρέθηκε η Στόχευση: Διαβάζετε τις μετρήσεις ενός ραντάρ σε ένα loop. Αν εντοπίσετε το νούμερο του εχθρού (π.χ. 99), σηκώνετε τον συναγερμό. Αν το loop ολοκληρωθεί και το ραντάρ δεν έπιασε τίποτα, τυπώστε το μήνυμα "All Clear".
    6. Hint: found = false. Στο loop, αν δεις τον στόχο, found = true. Έξω από το loop, κάνεις if !found { print("Clear") }.

4. Early Exit (Guard Clauses)

  1. Έλεγχος Έγκυρου Κωδικού Χρώματος: Φτιάξτε μια συνάρτηση που επιστρέφει true αν ένα string είναι έγκυρο χρώμα HEX. Πρέπει να έχει ακριβώς 7 χαρακτήρες, ο πρώτος να είναι το #, και να μην έχει γράμματα πάνω από το F. Κάντε exit αμέσως μόλις βρείτε ένα λάθος, αντί να βάλετε τα πάντα μέσα σε if.
    2. Hint: Αντί για if len == 7 { if startsWith... }, κάνεις if len != 7 return false, μετά if str[0] != '#' return false, κρατώντας τον κώδικα φλατ.
  2. Αναγνώριση Δίσεκτου Έτους: Ένα έτος είναι δίσεκτο αν διαιρείται με το 4. Εξαίρεση: αν διαιρείται με το 100 ΔΕΝ είναι, εκτός κι αν διαιρείται με το 400 που τελικά είναι. Σπάστε αυτή τη λογική σε μικρά, ξεχωριστά early exits.
    3. Hint: Τρία απλά διαδοχικά if (τα δύο πρώτα επιστρέφουν false, το τρίτο αν χρειάζεται). Στο τέλος return true.
  3. HTTP Request Validator: Μια συνάρτηση παίρνει τα headers μιας αίτησης. Αν το url είναι άδειο, αν το token λείπει, ή αν η μέθοδος δεν είναι POST, πρέπει να διακόψει την εκτέλεση αμέσως πετώντας error. Διαφορετικά προχωράει στην αποθήκευση.
    4. Hint: Σειρά από if που πετάνε errors αμέσως. Ό,τι επιβιώσει κάτω από αυτά τα if θεωρείται 100% valid request.
  4. Game Collision Check: Σε ένα παιχνίδι, η συνάρτηση checkCollision() κάνει βαρείς μαθηματικούς υπολογισμούς. Πριν τους κάνει, ελέγξτε αν ο παίκτης είναι εκτός οθόνης (ώστε να τερματίσετε τη συνάρτηση αμέσως) για να γλιτώσετε CPU.
    5. Hint: 3 guard clauses ελέγχουν τα βασικά όρια. Το βαρύ math τρέχει μόνο αν ο κώδικας φτάσει κάτω-κάτω.
  5. Αρχικοποίηση Βάσης Δεδομένων: Φτιάχνετε τη συνάρτηση connectDB(). Αν το σύστημα λέει ότι είστε ήδη συνδεδεμένοι, σταματήστε αμέσως. Αν λείπει το αρχείο ρυθμίσεων, σταματήστε αμέσως βγάζοντας error. Αν όλα πάνε καλά, τρέξτε τη βαριά σύνδεση στο τέλος της συνάρτησης.
    6. Hint: Προστατεύεις τη συνάρτηση από το να τρέξει διπλά ή με λανθασμένα δεδομένα, επιστρέφοντας αμέσως στην αρχή του function.

5. Loop Control (Break / Continue)

  1. Ανάγνωση μέχρι το EOF: Φτιάξτε ένα άπειρο loop for {} που ζητάει συνεχώς από τον χρήστη να πληκτρολογήσει μια εντολή. Αν ο χρήστης πληκτρολογήσει τη λέξη "EXIT", το πρόγραμμα πρέπει να τερματίσει το loop και να κλείσει.
    2. Hint: for { input = read(); if input == "EXIT" { break } }. Απλό και καθαρό.
  2. Φιλτράρισμα Αρχείων: Διαβάζετε τα ονόματα 100 αρχείων. Θέλετε να τυπώσετε το όνομα του καθενός. Όμως, αν δείτε ότι κάποιο αρχείο καταλήγει σε .tmp, θέλετε να το αγνοήσετε (skip) και να περάσετε κατευθείαν στο επόμενο, χωρίς να διακοπεί το loop.
    3. Hint: if hasExtension(".tmp") { continue }. Η συνέχεια του loop απλά αγνοείται για αυτό το αρχείο, χωρίς nested ifs.
  3. Όριο Προσπαθειών (Retry Limit): Το δίκτυο έχει πρόβλημα και το download αποτυγχάνει. Θέλετε να γράψετε ένα loop που δοκιμάζει το πολύ 5 φορές. Αν πετύχει, π.χ. στην 2η προσπάθεια, πρέπει να σταματήσει αμέσως να προσπαθεί.
    4. Hint: for i=0; i<5; i++ { err = download(); if err == nil { break } }.
  4. Έλεγχος Ύποπτων Λέξεων: Ένα bot διαβάζει τα μηνύματα σε ένα chat. Αν το μήνυμα περιέχει βρισιά, πρέπει να αγνοηθεί και να μην αποθηκευτεί στη βάση, αλλά το bot πρέπει να συνεχίσει να διαβάζει τα επόμενα μηνύματα.
    5. Hint: Το continue προσπερνάει το print() ή τη λειτουργία αποθήκευσης που βρίσκεται στο τέλος του loop.
  5. Εντοπισμός Πρώτου Λάθους: Διαβάζετε ένα μεγάλο αρχείο JSON. Στο πρώτο συντακτικό λάθος που θα βρείτε, δεν υπάρχει λόγος να συνεχίσετε, καθώς το αρχείο είναι κατεστραμμένο. Σταματήστε το loop εκείνη τη στιγμή βγάζοντας error.
    6. Hint: Δεν θες να γεμίσεις την οθόνη με 100 λάθη. Μόλις βρεις το 1ο, σταματάς την επεξεργασία του αρχείου (break).

6. Universal Check

  1. Μόνο Αριθμοί; (IsNumeric): Πώς μπορείτε να είστε 100% σίγουροι ότι το string "12345" δεν κρύβει κάπου ένα γράμμα; Ελέγξτε κάθε χαρακτήρα: αν έστω ένας δεν ανήκει στους αριθμούς ('0' έως '9'), τότε ολόκληρο το string απορρίπτεται.
    2. Hint: Loop χαρακτήρα-χαρακτήρα. Αν ο χαρακτήρας δεν είναι ανάμεσα στο '0' και το '9', κάνεις κατευθείαν return false (falsification).
  2. Είναι Όλοι Ενήλικες; Έχετε τα δεδομένα μιας παρέας 5 ατόμων που θέλει να μπει σε club. Αν έστω και ΕΝΑΣ από την παρέα είναι κάτω από 18 χρονών, ολόκληρη η παρέα δεν μπορεί να μπει (η συνάρτηση επιστρέφει false).
    3. Hint: Loop στους φίλους. Αν friend.Age < 18 { return false }. Αν τελειώσει το loop (κανένας δεν ήταν κάτω από 18), return true.
  3. Είναι Ταξινομημένο; (IsSorted): Σας δίνουν ένα array και σας λένε ότι είναι ήδη ταξινομημένο από το μικρότερο στο μεγαλύτερο. Πώς θα το ελέγξετε για να το επιβεβαιώσετε; (Έστω και μια παραφωνία, καταστρέφει τον κανόνα).
    4. Hint: Συγκρίνεις κάθε arr[i] με το arr[i+1]. Αν arr[i] > arr[i+1], δεν είναι ταξινομημένο, άρα return false.
  4. Όλα Μηδέν; Μια βάση δεδομένων έχει τα χρέη ενός πελάτη προς διάφορες τράπεζες [0, 0, 0, 50, 0]. Θέλουμε να ελέγξουμε αν τα έχει εξοφλήσει ΟΛΑ, προκειμένου να του δώσουμε νέο δάνειο.
    5. Hint: Ψάχνεις αν υπάρχει έστω και ένα arr[i] > 0. Αν βρεις, σημαίνει ότι υπάρχει χρέος (return false). Αλλιώς return true.
  5. Ισχυρό Password: Ένα password θεωρείται ισχυρό μόνο αν ικανοποιεί 3 διαφορετικές συνθήκες: Πρέπει να περιέχει (τουλάχιστον ένα) κεφαλαίο γράμμα, (τουλάχιστον ένα) μικρό, και (τουλάχιστον έναν) αριθμό.
    6. Hint: Αντί για universal, εδώ είναι existential (ψάχνουμε αν ΥΠΑΡΧΕΙ έστω ένα). Τρεις διακόπτες (hasUpper, hasLower, hasNum). Στο τέλος return και τα 3.

7. Previous Value (Deduplication)

  1. Μέτρηση Αλλαγών Φρουράς: Σας δίνεται ένα array που δείχνει το ID του υπαλλήλου σε κάθε ώρα της βάρδιας (π.χ. [1, 1, 1, 2, 2, 1]). Μετρήστε πόσες φορές η βάρδια άλλαξε χέρια (δηλαδή ο τρέχων υπάλληλος δεν είναι ο ίδιος με της προηγούμενης ώρας).
    2. Hint: prev = arr[0]. Αν το τρέχον arr[i] != prev, αυξάνεις έναν μετρητή και ενημερώνεις το prev = arr[i].
  2. Αφαίρεση Διπλών (Sorted Array): Σας δίνουν ένα ταξινομημένο array, π.χ. [1, 1, 2, 3, 3]. Τυπώστε τα στοιχεία στην οθόνη, αλλά μην τυπώσετε ποτέ το ίδιο νούμερο δύο φορές. Τα διπλότυπα πρέπει να αγνοηθούν.
    3. Hint: prev = -1 (ή κάτι άκυρο). Αν το num != prev, τύπωσε το num και κάνε prev = num. Τα διπλότυπα θα κοπούν.
  3. Διορθωτής Πληκτρολογίου: Κάποιος κράτησε πατημένο το πλήκτρο και έγραψε "hhheeeellooo". Γράψτε ένα πρόγραμμα που διαβάζει τα γράμματα, αλλά δεν αφήνει ΠΟΤΕ το ίδιο γράμμα να επαναληφθεί πάνω από 2 συνεχόμενες φορές.
    4. Hint: Κρατάς τον προηγούμενο χαρακτήρα και έναν μετρητή εμφανίσεων. Αν char == prev, count++. Αν count > 2, δεν τυπώνεις. Αν αλλάξει το γράμμα, count = 1.
  4. Συμπίεση Διαστημάτων: Ένα σύστημα κάνει Ping κάθε δευτερόλεπτο και βγάζει "SUCCESS" ή "FAIL". Αν έχουμε 10 συνεχόμενα "SUCCESS", μην τα τυπώσετε 10 φορές. Τυπώστε μια φορά το "SUCCESS x10".
    5. Hint: Όσο το string είναι ίδιο με το prev, απλά μετράς. Μόλις το string αλλάξει, τυπώνεις το [prev, count] και μηδενίζεις.
  5. Ανίχνευση Κορυφής (Peak Finding): Βρείτε αν σε ένα γράφημα τιμών μετοχής υπάρχει μια "κορυφή" — δηλαδή μια μέρα που η τιμή ήταν μεγαλύτερη από τη χθεσινή (άρα είχε άνοδο), αλλά και μεγαλύτερη από την αυριανή (άρα μετά έπεσε).
    6. Hint: loop από το 1 έως το n-2. Ελέγχεις if arr[i] > arr[i-1] && arr[i] > arr[i+1].

8. Two Pointers

  1. Έλεγχος Παλίνδρομου (Αριθμοί): Αν σας δοθεί ένα array με αριθμούς [1, 2, 3, 2, 1], πώς θα ελέγξετε αν διαβάζεται το ίδιο και από την ανάποδη; Αντί να φτιάξετε νέο, ανάποδο array, ελέγξτε τις άκρες του!
    2. Hint: start = 0, end = len-1. Σε ένα for start < end, ελέγχεις αν arr[start] != arr[end]. Μετά start++, end--.
  2. Διαχωρισμός (Partition) Θετικών-Αρνητικών: Έχετε ένα array γεμάτο θετικούς και αρνητικούς. Χρησιμοποιώντας δύο δείκτες στις άκρες, σπρώξτε όλους τους αρνητικούς στην αρχή του array και όλους τους θετικούς στο τέλος, κάνοντας in-place swaps.
    3. Hint: start και end. Ο start ψάχνει θετικό, ο end ψάχνει αρνητικό. Μόλις βρουν και οι δύο, κάνουν swap(arr[start], arr[end]).
  3. Συγχώνευση 2 Ταξινομημένων Arrays: Σας δίνονται δύο ήδη ταξινομημένα arrays (A και B). Ενώστε τα σε ένα νέο τρίτο array που θα είναι επίσης ταξινομημένο, επιλέγοντας κάθε φορά το μικρότερο από τα δύο στοιχεία που "κοιτάνε" οι δείκτες.
    4. Hint: i = 0 (στο 1ο array), j = 0 (στο 2ο array). Όποιο από τα δύο δείχνει σε μικρότερο νούμερο, μπαίνει στο νέο array και προχωράει ο δείκτης του.
  4. Dutch National Flag: Ένα array έχει μόνο τρεις αριθμούς: 0, 1, και 2 (σαν τα χρώματα μιας σημαίας). Ταξινομήστε το array (όλα τα 0 στην αρχή, τα 1 στη μέση, τα 2 στο τέλος) κάνοντας μόνο ένα πέρασμα, χρησιμοποιώντας 3 pointers.
    5. Hint: 3 δείκτες (low, mid, high). Τα 0 πάνε στην αρχή (swap με low), τα 2 στο τέλος (swap με high), τα 1 μένουν στη μέση.
  5. Find the Duplicate (Tortoise & Hare): Σε ένα array που οδηγεί σαν λαβύρινθος (η κάθε τιμή σε πάει στο επόμενο index), βρείτε αν υπάρχει κύκλος, βάζοντας δύο δείκτες να τρέχουν — ο ένας 1 βήμα τη φορά (χελώνα), ο άλλος 2 βήματα (λαγός).
    6. Hint: Ο slow pointer προχωράει 1 βήμα, ο fast 2 βήματα. Αν κάποια στιγμή βρεθούν στο ίδιο index (συμπέσουν), υπάρχει κύκλος.

9. Sliding Window

    6. Hint: Επειδή είναι 1-based (όχι 0-based), αφαιρούμε 1 πριν το modulo, και το ξαναπροσθέτουμε μετά: (10 + 15 - 1) % 12 + 1.

17. Stack (LIFO)

  1. Διαδρομή Φακέλου (Path Simplification): Σε συστήματα Linux, το path /a/./b/../../c/ έχει κρυφά νοήματα. Το . σημαίνει "μείνε εδώ", το .. σημαίνει "γύρνα πίσω". Χρησιμοποιήστε μια στοίβα για να βρείτε το πραγματικό path (που είναι το /c).
    2. Hint: Αν διαβάσεις όνομα φακέλου, κάνεις Push. Αν είναι .., κάνεις Pop (διαγράφεις τον τελευταίο φάκελο που μπήκες). Στο τέλος ό,τι έμεινε είναι το σωστό.
  2. HTML Linter: Ένας κειμενογράφος θέλει να ελέγξει αν κλείσατε σωστά όλα τα tags σας (π.χ.

    Hello

    ). Το κλείσιμο πρέπει πάντα να ταιριάζει με το πιο *πρόσφατο* άνοιγμα.
    3. Hint: Στο
    κάνεις Push. Στο
    κάνεις Pop και ελέγχεις αν το tag που βγήκε ήταν όντως
    . Στο τέλος το stack πρέπει να είναι εντελώς άδειο.
  3. Ιστορικό Browser (Back Button): Πώς λειτουργεί το κουμπί Πίσω στον Browser; Όταν κάνετε κλικ σε ένα link, η τρέχουσα σελίδα μπαίνει στην "κορυφή" μιας στοίβας.
    4. Hint: Στο Click -> Push(URL). Όταν πατήσεις Go Back, το σύστημα κάνει Pop() και σε πάει κατευθείαν στην τελευταία σελίδα.
  4. Επόμενος Μεγαλύτερος Αριθμός: Σας δίνεται ένα array [2, 1, 5, 3]. Για κάθε αριθμό, βρείτε ποιος είναι ο *πρώτος* μεγαλύτερος αριθμός στα δεξιά του (για το 2 είναι το 5, για το 1 είναι το 5, κ.ο.κ).
    5. Hint: Το Stack κρατάει στοιχεία που "περιμένουν" υπομονετικά να βρουν έναν μεγαλύτερο. Μόλις έρθει ένας μεγάλος αριθμός, κάνει Pop όλους τους μικρότερους!
  5. Αξιολόγηση Πράξεων με Προτεραιότητα: Φτιάχνετε έναν υπολογιστή τσέπης που διαβάζει τα σύμβολα ανάποδα (Reverse Polish Notation), π.χ. 3 4 + 2 *. Δεν χρειάζεται παρενθέσεις. Πώς θα το υπολογίσει η μηχανή;
    6. Hint: Στους αριθμούς κάνεις Push. Μόλις δεις πράξη (π.χ. +), κάνεις Pop 2 αριθμούς, τους προσθέτεις, και κάνεις Push το αποτέλεσμα πίσω στη στοίβα!

18. Greedy Algorithms

  1. Συμπίεση Αρχείων (Huffman Coding): Πώς φτιάχνονται τα zip αρχεία; Ο αλγόριθμος παίρνει τα γράμματα και "άπληστα" (greedy) ενώνει πρώτα τα 2 γράμματα που εμφανίζονται πιο σπάνια (έχουν τη μικρότερη συχνότητα).
    2. Hint: Επιλέγεις τα 2 στοιχεία με τις μικρότερες τιμές, τα αθροίζεις σε ένα νέο στοιχείο, και τα ξαναβάζεις στη λίστα. Επαναλαμβάνεις.
  2. Ελαχιστοποίηση Καθυστερήσεων (Job Sequencing): Είστε freelancer και έχετε πολλές δουλειές με deadlines και διαφορετικά κέρδη. Θέλετε να βγάλετε τα περισσότερα χρήματα. Η "άπληστη" λογική λέει ότι δίνετε προτεραιότητα στη δουλειά που πληρώνει περισσότερο!
    3. Hint: Ταξινομείς βάσει κέρδους (από το μεγαλύτερο στο μικρότερο). Παίρνεις την πιο κερδοφόρα και την τοποθετείς ΟΣΟ πιο κοντά στο deadline της γίνεται.
  3. Μοίρασμα Cookies στα Παιδιά: Κάθε παιδί θέλει ένα μπισκότο συγκεκριμένου μεγέθους. Έχετε μπισκότα διαφόρων μεγεθών. Πώς θα τα μοιράσετε ώστε να χορτάσουν όσο το δυνατόν περισσότερα παιδιά, χωρίς να σπαταλήσετε τα μεγάλα μπισκότα;
    4. Hint: Ταξινομείς τα παιδιά και τα μπισκότα. Δίνεις πάντα στο πιο "απαιτητικό" (αλλά εφικτό) παιδί, το μικρότερο μπισκότο που του κάνει.
  4. Minimum Spanning Tree (Δίκτυα): Πρέπει να ενώσετε 100 πόλεις με δρόμους, ξοδεύοντας τα λιγότερα χρήματα. Υπάρχουν χιλιάδες πιθανές συνδέσεις. Η άπληστη λογική λέει: "Φτιάξε πρώτα τον πιο φθηνό δρόμο!"
    5. Hint: Ταξινομείς τους δρόμους βάσει κόστους. Άπληστα επιλέγεις ΠΑΝΤΑ τον πιο φθηνό, αρκεί αυτή η προσθήκη να μην δημιουργεί "κύκλο" με τις ήδη ενωμένες πόλεις.
  5. Διάσωση με Βάρκες: Σε ένα πλοίο που βυθίζεται, κάθε βάρκα χωράει το πολύ 2 άτομα και έχει συγκεκριμένο όριο βάρους. Πώς θα διασώσετε τους πάντες με τις λιγότερες δυνατές βάρκες; Πρέπει να γίνουν οι σωστοί συνδυασμοί βαρών!
    6. Hint: Ταξινομείς τα άτομα ανά βάρος. Προσπαθείς πάντα να ενώσεις τον πιο ΒΑΡΥ μαζί με τον πιο ΕΛΑΦΡΥ. Αν το άθροισμα δεν χωράει, ο βαρύς φεύγει ολομόναχος στη βάρκα.
